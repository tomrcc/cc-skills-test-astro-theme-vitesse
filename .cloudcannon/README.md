# Vitesse site

A personal site with a blog, a projects page and a few standalone pages.

- [Pages](cloudcannon:collections/pages)
- [Blog](cloudcannon:collections/blog)

## Pages

The home page, the projects page and standalone pages such as Markdown Style.

- **Home and Projects** are built from sections. Open them in the Visual Editor to edit text in place, or add, remove and reorder sections from the sidebar. Sections: Page heading, Rich text, Social links, Contact email, Divider and Project group.
- **Standalone pages** have a title, an optional image and a body of text.
- **Add a page** with **+ Add**: choose **Page** for a simple text page, or **Page Builder** for a page made of sections.
- **New pages** show a preview of an existing page until the site rebuilds: a new **Page** previews the Markdown Style page, and a new **Page Builder** page previews the home page. If the Markdown Style page is deleted or renamed, new simple pages have no preview until they are saved and built.

## Blog

Posts, notes and talks. Each lives in its own folder, and the folder decides which tab on the blog page lists it.

- **Add** with **+ Add**: **Blog post**, **Note** or **Talk** each creates the file in the right folder. New posts open in the Content Editor.
- **Drafts** stay off the published site until **Draft** is turned off.
- **Redirect link** makes the post list link somewhere else instead of the post.
- **Language** set to Chinese shows a 中文 marker in post lists.

## Site settings

- **Site**: site title, description, author, contact email, logo and default share image.
- **Navigation**: the header links and the tabs on the blog page. A blog tab path must be `/blog` or `/blog/` followed by a folder name in the blog.
- **Social links**: the links on the home page. Pick a **Header icon** to also show a link in the site header.
- **Footer**: footer links and the licence link.

Icons are picked from a fixed list. Ask a developer to add a new one.

## Editing on the page

- **Click text to edit it** in the Visual Editor: titles, headings, rich text, page and post bodies, post duration and tag, project names and descriptions.
- **Shared text is editable on any page**: the home page's social links and contact email, and the footer links, licence and author. Changes save to Site settings and show on every page.
- **The site header** is edited in Site settings only: Navigation for its links, Site for the logo, Social links for its icons.
- **Some changes show after the site rebuilds**: post dates, link addresses, and footer links added or removed.
